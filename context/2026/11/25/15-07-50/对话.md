### 1. 使用脚本检测

```bash
# 检测单个 TCP 端口（默认超时 3 秒）
./check_port.sh 127.0.0.1 8080

# 指定超时时间并一次检测多个端口
./check_port.sh -t 2 example.com 80 443 8080
```

脚本行为说明：
- 基于系统 `nc` 检测 TCP 端口，在 macOS 下自动使用 `-G` 与 `-w` 控制超时，在 Linux 下使用 `-w`。
- 参数校验涵盖主机、端口范围（`1` 到 `65535`）与正整数超时时间。
- 退出码：`0` 表示全部连通，`1` 表示存在不可达端口，`2` 表示参数错误或缺少 `nc`。

### 2. 常用 Shell 单行命令

```bash
# macOS（BSD nc）
nc -zv -G 3 -w 3 <主机> <端口>

# Linux（OpenBSD/GNU nc）
nc -zv -w 3 <主机> <端口>

# 无 nc 时使用 Bash 内置 /dev/tcp
bash -c 'timeout 3 bash -c "</dev/tcp/<主机>/<端口>"' && echo "通" || echo "不通"

# 使用 curl 检测 TCP 连通性
curl -s --connect-timeout 3 telnet://<主机>:<端口>
```

### 3. 已完成的验证

- 语法与参数检查：`bash -n check_port.sh` 通过，`-h`、缺失参数、非法端口 `70000` 和非法超时 `0` 均按预期返回退出码 `2`。
- 真实端口测试：在本机监听临时 TCP 端口并对比关闭端口，确认连通端口输出 `[OK]` 且返回 `0`，关闭端口输出 `[FAIL]` 且返回 `1`，多端口组合输出各自状态并返回 `1`。

> 注：如果本机开启了代理（例如 TUN 或 Fake-IP 模式），对外部域名执行端口检测时可能由代理接管连接并返回连通结果；排查真实直连状态时请使用目标 IP 或在无代理环境下检测。
