# 对话归档

## 用户

我不知道怎么做（附题目截图：洛谷 P5729【深基5.例7】工艺品制作）

## 助手

妹妹，这道题（洛谷 P5729【深基5.例7】工艺品制作）属于三维数组模拟题。

### 为什么不能直接用总体积减去每次切割的体积

题目可能会进行多次切割，不同切割切出的长方体空洞**可能重叠**。直接把每次切掉的体积相减，会把重叠部分的小方块重复扣除，导致答案偏小。

### 解题思路

先看题目给出的数据范围：$1 \le w, x, h \le 20$，$1 \le q \le 100$。整个立方体最多包含 $20 \times 20 \times 20 = 8000$ 个小方块，最多操作 100 次，总计算量最多约 $8 \times 10^5$ 次，直接用**三维数组**记录每个小方块的状态即可：

1. **建立三维数组标记状态**：定义一个三维数组 `a[25][25][25]`，初始值全为 `0`。用 `a[i][j][k] == 0` 表示坐标 $(i, j, k)$ 的小方块还在，用 `a[i][j][k] == 1` 表示这个小方块已被激光蒸发。
2. **模拟每次切割**：依次读入 `q` 组 $(x_1, y_1, z_1)$ 和 $(x_2, y_2, z_2)$，用三层循环遍历所有满足 $x_1 \le i \le x_2$、$y_1 \le j \le y_2$、$z_1 \le k \le z_2$ 的坐标，将 `a[i][j][k]` 设为 `1`。同一个方块被切到多次时，重复赋值为 `1` 不会产生额外扣除，自然解决了重叠问题。
3. **统计剩余方块数量**：全部切割完成后，用三层循环遍历整个立方体（`i` 从 `1` 到 `w`，`j` 从 `1` 到 `x`，`k` 从 `1` 到 `h`），统计 `a[i][j][k] == 0` 的个数并输出。

### C++ 参考代码

```cpp
#include <iostream>
using namespace std;

int a[25][25][25]; // 全局数组自动初始化为 0，0 表示未切，1 表示已切

int main() {
    int w, x, h, q;
    cin >> w >> x >> h >> q;

    while (q--) {
        int x1, y1, z1, x2, y2, z2;
        cin >> x1 >> y1 >> z1 >> x2 >> y2 >> z2;

        for (int i = x1; i <= x2; i++) {
            for (int j = y1; j <= y2; j++) {
                for (int k = z1; k <= z2; k++) {
                    a[i][j][k] = 1;
                }
            }
        }
    }

    int ans = 0;
    for (int i = 1; i <= w; i++) {
        for (int j = 1; j <= x; j++) {
            for (int k = 1; k <= h; k++) {
                if (a[i][j][k] == 0) {
                    ans++;
                }
            }
        }
    }

    cout << ans << endl;
    return 0;
}
```

### 容易出错的地方

- **数组初始化**：把 `a` 定义在 `main` 函数外面（全局变量）会自动全为 `0`；如果写在 `main` 函数里面，需要写成 `int a[25][25][25] = {0};`，避免残留随机值。
- **数组长度**：坐标从 `1` 到 `20`，数组每一维长度至少为 `21`，设为 `25` 可以避免下标越界。
- **循环边界对应关系**：三层循环统计剩余方块时，`i` 对应 `w`（第一维），`j` 对应 `x`（第二维），`k` 对应 `h`（第三维），不要把边界顺序写错。
