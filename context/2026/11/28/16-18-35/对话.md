# 对话归档

## 用户

（附终端截图：在服务器 `/www/wwwroot/ARTEX.happanetwork.com/ARTEX` 目录手动下载新版 `docker-compose` 插件后执行 `docker compose up -d --build`，报错 `compose build requires buildx 0.17.0 or later`）

## 助手

妹妹，这个报错 `compose build requires buildx 0.17.0 or later` 是因为刚刚手动下载了最新版的 `docker-compose` 插件，它执行 `--build` 时依赖 `0.17.0` 及以上版本的 `docker-buildx` 插件，而当前服务器尚未安装或版本过低。

按你刚才安装 `docker-compose` 的同一路径，直接下载最新版 `docker-buildx` 插件即可：

```bash
ARCH=$(uname -m)
case "$ARCH" in
  x86_64) ARCH="amd64" ;;
  aarch64) ARCH="arm64" ;;
esac
VER=$(basename "$(curl -Ls -o /dev/null -w '%{url_effective}' https://github.com/docker/buildx/releases/latest)")
mkdir -p /usr/local/lib/docker/cli-plugins
curl -fSL "https://github.com/docker/buildx/releases/download/${VER}/buildx-${VER}.linux-${ARCH}" -o /usr/local/lib/docker/cli-plugins/docker-buildx
chmod +x /usr/local/lib/docker/cli-plugins/docker-buildx
```

安装完成后验证版本，再重新启动构建：

```bash
docker buildx version
docker compose up -d --build
```

如果 `docker buildx version` 显示的仍是旧版本，说明 `/root/.docker/cli-plugins/docker-buildx` 下存在优先级更高的旧插件，删除该文件后再检查版本即可。
